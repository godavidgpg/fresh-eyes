# 디자인 감각: 의도적으로 디자인돼 보이는가

5단계에서 쓴다. AI 티 신호와 기준값의 상당 부분은 **unslop**(Damir Sokolovsky, [@heydamir](https://x.com/heydamir), CC BY 4.0, https://github.com/heydamir/unslop)의 진단 체계를 **고치기가 아니라 평가하기** 용도로 각색했다. unslop의 핵심 관점은 이렇다.

> 조잡한 화면은 색과 효과를 크롬(배경, 버튼, 테두리, 라벨)에 흩뿌린다. 잘 만든 화면은 크롬을 조용히 두고, 사람들이 기억할 한두 개의 콘텐츠 순간에 풍부함을 모은다.

평가자는 이 관점으로 본다. **풍부함이 어디에 쓰였는가?**

## 1. 9개 차원 루브릭 (각 1~5점, 45점 만점)

점수마다 스크린샷 근거 한 줄을 붙인다. 측정 단서는 [scripts/tokens.js](../scripts/tokens.js)의 출력 필드다.

| 차원 | 5점은 이렇다 | 2점 이하 신호 | 측정 단서 |
|---|---|---|---|
| **1. 위계와 타이포그래피** | 제목, 본문, 보조 정보가 3~4단계로 또렷하다. 위계를 굵기가 아니라 크기와 색으로 만든다. 본문은 16px 안팎, 줄 간격은 1.4~1.6, 한 줄은 45~75자(한글 25~40자). 숫자는 tabular-nums에 형식이 하나다 | 크기가 다 비슷하다, 800~900 굵기의 제목, 대문자에 자간을 넓힌 라벨, 작은 글자에 음수 자간 | `fontSizes` ≤ 6종, `fontFamilies` ≤ 2, `heavyWeights`, `upperTracked` |
| **2. 간격과 리듬** | 4px 그리드를 따른다. 같은 것은 같은 크기다. 그룹 안의 간격은 그룹 사이보다 좁다 | 13, 17, 22처럼 제멋대로인 값, 형제 카드마다 다른 패딩, 위는 휑하고 아래는 빽빽함 | `offGrid4pxShare` < 0.2 |
| **3. 정렬과 그리드** | 왼쪽 경계선이 몇 개로 정리돼 있다. 아이콘은 한 열, 숫자는 오른쪽 정렬로 한 열 | 1~4px씩 어긋난 경계, 아이콘과 글자의 세로 중심이 안 맞음, 긴 글까지 전부 가운데 정렬 | `alignmentNearMisses` |
| **4. 색** | 중립색 단계 하나에 텍스트 역할 3개(주, 보조, 흐림). 강조색은 하나이고 행동, 선택, 핵심 수치에만 쓴다. 의미 색(성공, 오류)은 톤을 낮춰 팔레트 안에 있다. 테두리는 6~10% 불투명도의 머리카락 선 | 보라→파랑 그라데이션, 컬러 글로우, 비슷한 라벤더 다섯 가지, 모든 것이 강조됨, 네온 테두리 | `textColors` ≤ 5, `gradientSurfaces`, `glowShadows` |
| **5. 아이콘과 컴포넌트** | 아이콘 세트는 하나, 크기 하나, 선 굵기 하나이고 텍스트 색을 따른다. 모서리는 크기에 따라 정해지고 안쪽 반경은 바깥 반경에서 패딩을 뺀 값이다. 버튼, 입력칸, 카드가 화면끼리 통일돼 있다 | 이모지 아이콘, 아이콘마다 다른 색, 모든 게 알약 모양, 화면마다 다른 둥글기와 그림자 | `emojiInUI`, `radii` ≤ 4종, `shadowKinds` ≤ 3 |
| **6. 상호작용 상태** | hover, focus, pressed, disabled, loading이 모두 디자인돼 있고 팔레트 안에 있다. 키보드 포커스 링이 보인다. 선택 상태가 은은한 표면 단계로 표시된다 | 상태 변화가 없다, 브라우저 기본 포커스뿐이거나 아예 없다, 활성 항목에 그라데이션과 글로우 | hover, focus, pressed 스크린샷 비교 |
| **7. 모션** | 움직임이 무언가를 설명한다. 이징 곡선은 하나, 지속 시간은 몇 종류뿐이다. 로딩 시 진입 애니메이션은 한 번 | 살아 있지 않은 것에 pulse, ping, 숨 쉬는 글로우, `transition: all`, 카드 hover 확대, 통통 튀는 스프링, width/height/top 애니메이션 | `infiniteAnimations`, `transitionAll` |
| **8. 콘텐츠와 문구** | 헤드라인이 이 제품이 누구에게 무엇을 하는지 말한다. 데이터가 그럴듯하다. 변화량에 비교 대상이 있다("지난달보다 +12%") | 인사말 헤드라인, 느낌표, 과장어, 확인 불가한 주장, `$123,456`과 `[X]`, lorem, 깨지거나 늘어난 이미지 | `exclamations`, `badImages` |
| **9. 정체성** | 이 제품만의 디테일이 하나 있고 일관되게 쓰인다. 풍부함은 한두 개의 콘텐츠 순간에 모여 있다 | 템플릿 테스트 실패: 제품 이름만 바꾸면 다른 제품이라고 해도 믿을 화면 | 템플릿 테스트 |

**판정**: 38점 이상이면 출시 가능한 완성도, 29~37점은 다듬으면 좋아짐, 28점 이하는 디자인 시스템부터 다시 잡아야 한다.

**좋은 화면 처리**: 2점 이하 신호가 거의 없으면 점수를 억지로 깎지 않는다. "잘 만들었다"고 말하고, 정확한 값과 함께 작은 개선 2~3개만 제안한다 (unslop의 "좋은 화면은 다르게 만들려고 바꾸지 않는다" 원칙).

## 2. AI 티 신호 (빠른 스캔용)

unslop의 `signs.md`를 평가용으로 압축했다. 발견하면 위치와 함께 적고 해당 차원 점수에 반영한다.

**표면과 색**: 보라→파랑, 보라→분홍 그라데이션 배경과 버튼 · 그라데이션 텍스트 · 컬러 글로우 그림자 · 콘텐츠 뒤의 방사형 색 번짐과 흐린 블롭 · 흰색 안쪽 하이라이트와 컬러 그림자를 단 글래스 카드

**타입**: 800~900 굵기 제목 · `NAVIGATION` 같은 대문자 자간 라벨 · `$48,210` 옆에 `$124,860.40` 같은 섞인 숫자 형식 · 강조용 이탤릭

**아이콘**: 내비, 라벨, 상태에 쓴 이모지(🏠 🚀 💰 🔥) · AI 기능마다 붙은 ✨ · 여러 크기와 색이 섞인 아이콘

**컴포넌트**: 개수, 요금제, 단축키에 쓴 빛나는 알약 · 어디에나 붙은 `PRO`, `New ✨`, `Beta 🚀` · 모든 통계 카드에 붙은 스파크라인 · 같은 너비, 같은 구성의 카드가 나란히 반복됨 · 무지개 막대 차트

**랜딩**: 헤드라인 위의 `✨ Introducing X 2.0` 알약 · 어느 제품에나 맞는 헤드라인("AI로 워크플로를 극대화하세요") · 전부 가운데 정렬로 쌓인 히어로 · 버튼 3개 이상 · 출처 없는 "10,000+ 팀이 신뢰" · 의미 없는 블롭, 오브, 로봇, 빛나는 뇌

**모션**: 살아 있지 않은 것의 `animate-pulse` · `transition-all`과 `hover:scale` · 사방에서 날아 들어오는 요소 · 패럴랙스

**템플릿 냄새** (조잡하진 않지만 아무도 결정하지 않은 모습): 순수 회색 배경, Inter, 흰 글자, 버튼 하나만 브랜드 색 · 빈 상자거나 일반적인 히어로 비주얼

## 3. 수정안 쓰는 법

- "더 예쁘게"는 수정안이 아니다. **토큰 단위로** 쓴다. "글자 크기 11종을 12/14/16/20/28/40 6단계로", "간격을 4/8/12/16/24/32/48로", "회색 7종을 텍스트 역할 3개로(#171717, #525252, #737373)".
- 효과가 큰 순서는 대개 간격 → 색 → 아이콘 → 문구 → 타입 → 레이아웃 → 디테일 → 모션 순이다 (unslop의 9단계 패스 순서). 간격을 먼저 고치는 이유는 리듬이 잡히면 나머지가 다르게 읽히기 때문이다.
- 사용성을 해치는 제안(대비 낮추기, 라벨을 지우고 아이콘만 남기기, 터치 타깃 줄이기)은 하지 않는다.
- 사용자가 화면을 직접 고쳐주길 원하면 unslop 스킬을 쓰라고 안내한다. 이 스킬은 판정과 근거를 내는 데까지만 한다.

## 4. 참고 기준값 (unslop tokens 발췌)

- 간격 스케일: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128
- 행 높이: 촘촘 32, 기본 36, 터치 40~44. 내비게이션 행 32~36에 간격 2~4
- 사이드바 240~280, 콘텐츠 최대 1440~1600, 상단 바 56~64
- 모서리: 컨트롤 8~10, 카드 12~16, 패널 14~20. 안쪽 반경 = 바깥 반경 − 패딩 (최소 4)
- 아이콘: 16 또는 18px, 선 1.5
- 굵기: 400과 500, 드문 강조에 600
- 대비: 강조색 위의 글자는 4.5:1 이상, 흐린 텍스트도 4.5:1 가까이
