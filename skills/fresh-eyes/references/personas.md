# 페르소나: 누구의 눈으로 볼 것인가

"사람처럼"이라고 해도 사람은 한 종류가 아니다. 페르소나마다 **행동 파라미터**를 정해 두고, 그 값대로 판단한다. 예를 들어 아이콘 이해도가 "낮음"이면 라벨 없는 아이콘은 확신도를 한 단계 낮춘다.

## 파라미터

| 파라미터 | 값 | 판단에 주는 영향 |
|---|---|---|
| **어휘** | 일반 / 업계 / 개발자 | 일반이면 업계 용어와 영문을 모르는 말로 본다 |
| **아이콘 이해도** | 낮음 / 보통 / 높음 | 낮음이면 돋보기, 집, X, 휴지통 말고는 라벨이 필요하다고 본다 |
| **기기와 자세** | 모바일 한 손 / 모바일 두 손 / 데스크톱 마우스 / 키보드 전용 | 터치 타깃과 엄지 영역 기준이 달라진다 |
| **시력** | 보통 / 노안 / 저시력 / 색각 이상 | 글자 크기, 대비, 색에만 의존한 정보의 기준이 달라진다 |
| **인내심** | 높음 / 보통 / 낮음 | 낮음이면 1초가 넘는 대기와 두 번 이상의 되돌아감을 이탈로 본다 |
| **목적의 급함** | 둘러보기 / 볼일 보기 / 급함 | 급하면 훑기만 하고 첫 번째 그럴듯한 것을 누른다 (만족화) |

## 기본 페르소나 세트

### A. 처음 온 일반 사용자 (기본값)
어휘 일반, 아이콘 보통, 모바일 한 손, 시력 보통, 인내심 보통, 볼일 보기.
**중점**: 5초 테스트, Blind Control Reading, 첫 태스크의 클릭 수.

### B. 50~60대, 디지털에 덜 익숙한 사용자
어휘 일반, 아이콘 낮음, 모바일 두 손, 노안, 인내심 보통, 볼일 보기.
**중점**: 본문 16px 이상, 라벨 없는 아이콘, 스와이프와 길게 누르기처럼 숨은 제스처, 자동으로 넘어가는 캐러셀, 되돌릴 수 없을 것 같아 누를 용기가 안 나는 버튼, 확인 없이 일어나는 결제.
**시뮬레이션**: `document.body.style.zoom='1.5'` 또는 OS 글자 크기 확대를 가정하고 레이아웃이 깨지는지 본다.

### C. 바쁜 반복 사용자 (파워 유저)
어휘 업계, 아이콘 높음, 데스크톱, 인내심 낮음, 급함.
**중점**: 키보드 단축키, 명령 팔레트, 기본값과 최근 항목, 일괄 처리, 매번 뜨는 확인창과 온보딩의 반복, 응답 속도 (Nielsen #7 유연성과 효율).

### D. 저시력 또는 색각 이상 사용자
어휘 일반, 아이콘 보통, 데스크톱 200% 확대, 저시력 또는 색각 이상, 인내심 보통.
**중점**: 대비(WCAG 1.4.3), 200% 확대와 320px 리플로(1.4.10), 색만으로 전달하는 정보(1.4.1, 흑백 테스트), 포커스 표시.
**시뮬레이션**: 흑백 필터, `browser_resize` 320×800, 확대.

### E. 키보드 또는 스크린 리더 사용자
어휘 일반, 키보드 전용.
**중점**: Tab 순서, 보이는 포커스, 모달 포커스 가두기, Esc로 닫기, 접근성 이름이 보이는 라벨과 같은가(2.5.3), `div`로 만든 가짜 버튼(`perceive.js`의 `fakeButton`).
**이 페르소나만은 snapshot이 곧 "보이는 화면"이다.** 스크린 리더 사용자는 접근성 트리를 듣는다. 그러니 snapshot을 그 사람의 화면으로 읽고, 이름 없는 버튼과 의미 없는 링크 텍스트("여기", "더보기")를 찾는다.

### F. 산만한 상황의 사용자
어휘 일반, 모바일 한 손, 인내심 낮음, 지하철에서 한 손으로.
**중점**: 작업 중간에 앱을 나갔다 돌아와도 상태가 남는가, 실수로 누르기 쉬운 위험한 버튼, 한 화면에 한 가지 일만 하는가.

### G. 한국어가 서툰 사용자
어휘 일반, 한국어 중급.
**중점**: 줄임말과 신조어, 은유적인 버튼 라벨, 아이콘에만 의존한 의미, 번역기에 넣었을 때 의미가 유지되는 문장인가.

## 쓰는 법

1. 서비스의 실제 사용자와 가장 가까운 페르소나 1개를 주 페르소나로 정하고, 위험이 큰 페르소나 1개(대개 B나 D)를 보조로 고른다.
2. 보고서 맨 위에 페르소나와 파라미터 값을 적는다.
3. 지적마다 **누구에게 문제인지** 적는다. 모든 사람에게 문제인 것이 가장 위로 간다.
4. 페르소나는 근거가 아니라 **판단 기준**이다. "50대는 못 쓸 것"은 추정이므로 관찰 근거(글자 14px, 라벨 없는 아이콘 5개)와 함께 쓴다.
