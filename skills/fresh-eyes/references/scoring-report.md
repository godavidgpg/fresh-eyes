# 판정과 보고서

## 1. 심각도 (Nielsen 0~4)

빈도(얼마나 자주 마주치나), 영향(극복할 수 있나), 지속성(한 번 알면 괜찮나)을 함께 보고 매긴다 (Nielsen 1994).

| 등급 | 의미 | 예 |
|---|---|---|
| **4 치명** | 핵심 태스크를 못 끝낸다, 데이터를 잃는다, 돈이나 신뢰를 잃는다, 잘못된 결과를 믿게 만든다 | 제출 실패 후 입력값 소실, 연타로 중복 결제, 숨은 자동 결제 |
| **3 큰 문제** | 끝내긴 하지만 크게 망설이거나 우회해야 한다 | 핵심 행동이 아이콘뿐이라 못 찾음, 이유 없는 비활성 버튼 |
| **2 작은 문제** | 거슬리고 느려지지만 스스로 극복한다 | 보조 기능의 애매한 아이콘, 간격 불일치 |
| **1 외관** | 시간 날 때 고칠 것 | 1px 어긋난 정렬 |
| **0** | 문제 아님 | 기록하지 않음 |

보정 규칙
- 여러 페르소나에게 공통인 문제는 한 단계 올린다. 특정 페르소나에게만 해당하는 문제라도 그 페르소나가 주 사용자이면 내리지 않는다.
- 내 판단과 Fresh eyes 서브에이전트 판단이 모두 틀린 요소는 그대로 두고, 한쪽만 틀렸으면 한 단계 내린다.
- 확인하지 못하고 추정한 문제는 "(추정)"이라고 표시하고 최대 2로 둔다.

## 2. 점수

### UX 점수 (25점)
각 1~5점이고, 근거 한 줄씩을 붙인다.

| 차원 | 5점은 이렇다 |
|---|---|
| **첫 눈 명확성** | 5초 안에 무슨 서비스인지와 첫 행동이 분명하다. 예상 시선 1~2위가 의도한 핵심 요소다 |
| **이해 가능성** | Blind 표에서 핵심 요소의 추측이 모두 맞았다. 숨은 어포던스와 거짓 어포던스가 없다 |
| **태스크 효율** | 핵심 태스크를 되돌아가지 않고 최소 클릭으로 끝냈다 |
| **피드백과 상태** | 모든 행동에 시선 안에서 피드백이 있다. 빈 상태, 로딩, 에러, 새로고침을 견딘다 |
| **포용성** | WCAG 2.2 AA 핵심 항목을 통과하고, 보조 페르소나도 태스크를 끝낼 수 있다 |

### 디자인 감각 점수 (45점)
[visual-craft.md](visual-craft.md)의 9개 차원 루브릭.

### 출시 판정
점수보다 **심각도가 우선한다.**
- **보류**: 심각도 4가 하나라도 있다. 또는 UX 점수가 15점 이하다.
- **고치고 출시**: 심각도 3이 1개 이상이다. 또는 디자인 감각이 28점 이하다.
- **출시 가능**: 심각도 3 이상이 없고, UX 점수 20점 이상, 디자인 감각 29점 이상이다.
